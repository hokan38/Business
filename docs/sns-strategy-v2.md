## 1. 基本構造: 「リプライで届け、プロフィールで信頼させ、固定ポストで登録させる」

```
【毎日】価値リプライ 3〜5件（X）／価値コメント 1〜2件（LinkedIn）
   ↓ 有力アカウントの読者があなたのリプライを見る
【受け皿1】プロフィール（表示名・bio・これまでのリプライの品位）
   ↓ プロフィールアクセス
【受け皿2】固定ポスト = 創業マニフェスト（Premium長文）＋ 投稿在庫（平日1本の陳列棚）
   ↓ 深い接触
【転換】事前登録LP（公開後）／それまではフォローが転換ゴール
```

- **投稿100本の役割**: リプライ経由で来た訪問者が過去投稿を遡ったときの「信頼の陳列棚」。平日1本×在庫消化で約20週分。新規制作は不要。
- **教科書24章構想**: note連載ではなく、在庫の長文ポスト（X-002/005/007等）＋必要時の**X長文ポスト**として月2〜3本のペースで消化する形に変更。

## 2. 週次運用モデル（合計 約10h）

| 活動 | 頻度・量 | 週工数 | 担い手 |
|---|---|---|---|
| 価値リプライ（X） | 毎日3〜5件（週25件前後） | 6.0h | **Claude巡回・文案 → 代表が確認・送信**（1件あたり確認3〜5分） |
| 価値コメント（LinkedIn） | 平日1〜2件（週7件前後） | 1.5h | 同上 |
| X投稿 | 平日1本（在庫キューから自動投稿） | 0.5h（週1回のキュー積み＝承認） | 代表がキュー承認、API自動投稿 |
| LinkedIn投稿 | 週2本（在庫からコピペ） | 0.5h | 代表 |
| DM対応・定型返信 | 都度 | 0.5h | 代表（定型文はv1 §8-2） |
| 計測・週次振り返り | 週1回 | 0.5h | Claude集計 → 代表確認 |
| アドバイザー候補の関係構築 | 週次（45日目〜打診） | 0.5〜1.0h | 代表（リプライ運用と兼ねる） |

**リプライ運用の日次ワークフロー**:
1. Claudeが毎朝、[巡回リスト30件](./reply-target-accounts.md)＋テーマキーワードをWeb検索で巡回
2. 候補3〜5件を「対象ポストURL＋文案＋狙い」の形で届ける
3. 代表がXアプリで開いて文脈確認（30秒）→ 必要なら修正 → 送信
4. 送信できなかった件・反応は翌朝Claudeに共有（学習して精度を上げる）

## 3. リプライの品質基準（主エンジンの生命線）

v1の運用ルールを継承し、リプライ中心化に伴い格上げする:

- **1件の価値 > 件数**。本文より価値のある補足（データ・構造・実務の一次情報）だけを送る。書くことがない日は送らない
- 同一アカウントへは週1件まで。30件のリストに分散
- 反論・訂正・論争はしない。「補助線を1本足す」姿勢
- 政治・炎上中の話題・特定企業批判スレには絡まない（対象外2件は常時リプライ禁止）
- 自社宣伝はリプライに書かない。転換はプロフィールに任せる
- **スパム対策**: リプライ数を1日5件超に増やさない。定型文の使い回しをしない（新規アカウントの大量リプライはスパム判定の典型パターン）

## 4. LinkedInの運用（コメント文化を利用）

LinkedInはコメントが自分のネットワークのフィードに露出する設計のため、コメント運用の費用対効果がXより高い:

- 対象: 人事・HR経営者・エージェント業界人の投稿（巡回リストの該当者＋LinkedInで新規発見）
- 投稿は週2本、[LinkedIn在庫100本](./sns-posts-linkedin.md)から。アドバイザー開拓兼用（LI-071〜085）は45日目以降
- コネクション申請は週5件以内・全件個別文面（v1の規律を継承）
- **LinkedInはアドバイザー第1期生の主要開拓チャネルを兼ねる**。コメント関係の構築がそのまま打診の下地

## 5. KPI（リプライ中心版に差し替え）

**North Star は変更なし**（許可取得前: 事前登録リスト件数）。先行指標をリプライ系に差し替える:

| 階層 | 指標 | 目安（90日・仮置き） |
|---|---|---|
| 活動量 | リプライ送信数（週） | 25件/週を維持 |
| 反応 | リプライへのいいね・返信率 | 送信の30%に何らかの反応 |

| 転換2 | フォロワー | 90日で1,000〜1,500（v1と同水準） |
| 転換3 | 固定ポストのリンククリック → LP登録 | LP公開後に計測開始 |

**30日関門の判定指標（v1のnote指標を差し替え）**:

| 指標 | 合格 | 工程変更 |

| プロフィールアクセス→フォロー転換 | 計測して基準値化 | bioと固定ポストを改修 |

## 7. このピボットのリスク（正直な評価）

1. **検索流入資産（note SEO）を放棄する** — リプライは即効性がある代わりにストックされない。6ヶ月時点でフォロワー成長が頭打ちになったら、note再開を検討する（その時は在庫の長文をnote記事化するだけなので着手コストは低い）
2. **相手依存** — リプライの露出は相手の投稿頻度・アルゴリズムに依存。巡回リストを四半期ごとに見直し、反応の良い相手に配分を寄せる
3. **X一極集中** — アカウント凍結が単一障害点になる。LinkedInの並行運用と、フォロワーをメールリスト（LP）へ逃す導線を早期に作ることが保険。**LPの優先度はv1より上がる**（次の制作タスク）
