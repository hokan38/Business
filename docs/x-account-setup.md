# X 新規アカウント開設・立ち上げ手順（代表個人）

**準拠**: [SNS戦略書](./sns-strategy.md) §5 アカウント設計 ／ **作成日**: 2026年7月5日

新規アカウントは開設直後の数週間が最も凍結されやすいため、「手動ウォームアップ2週間 → 3週目からAPI自動投稿」の段階移行で立ち上げる。

---

## 1. 開設日にやること（30分）

- [ ] X アカウント開設（代表実名）。ハンドルは「氏名ローマ字」または「氏名＋markgate」形式
  - 例: `@taro_markgate` / `@yamada_markgate`（本名が決まり次第確定）
- [ ] **電話番号認証を必ず完了**（凍結耐性の基本）
- [ ] 2要素認証を有効化
- [ ] プロフィール設定（下記§2の文をコピペ。ヘッダー画像はネイビー×ゴールドのブランドテンプレで後日差し替え可）
- [ ] **X Premium に加入**（月額約1,000円〜。凍結耐性・リーチ・リプライ表示順・信頼シグナル。実質必須）
- [ ] 同日にハンドルの一括確保: X公式（`@MarkGate_jp` 等）/ note / LinkedIn / Threads
  - 公式アカウントは確保のみ。運用開始はプロフィール整備後
- [ ] **この日はフォロー・投稿をしない**（開設即大量アクションはスパム判定要因）

## 2. プロフィール文（コピペ用・文字数制限検証済み）

**表示名**（50文字制限・30文字） ※【氏名】を差し替え

> 【氏名】｜MarkGate代表｜"担当者ガチャ"を終わらせる

**自己紹介（採用: 案A・課題起点）**（160文字制限・128文字）

> ハイクラス転職は「どのサービスか」ではなく「誰が担当か」で決まる。なのに担当者は、選べない——だから各社の実績トップクラスのアドバイザーだけを審査制で束ね、求職者が"指名"できる仕組みを作っています。2026年内開始予定（有料職業紹介事業 許可申請準備中）

**自己紹介（予備: 案B・ブランドコピー起点）**（133文字）

> キャリアの質は、"誰と出会うか"で決まる。各社の実績トップクラスのキャリアアドバイザーだけを審査制で束ね、求職者が"指名"できるハイクラス転職プラットフォームを準備中。人材紹介の構造問題を言語化して発信します。2026年内開始予定（有料職業紹介事業 許可申請準備中）

**その他の欄**: 場所=東京（未定なら空欄可）／ウェブサイト=LP公開後に設定／誕生日=設定しない

※ 連載「ハイクラス転職の教科書」への導線はbioに入れず、マニフェストnote公開後（Day 12前後）の固定ポストが担う。
※ 表示名・アイコンを確定させてから Premium に加入する（加入後の変更は認証マークの再審査対象になることがある）。

**X（公式・確保用）**

> トップアドバイザーだけが、開ける扉。｜MarkGateはハイクラス転職のためのアドバイザー指名プラットフォームです。各人材紹介会社で実績トップクラスのキャリアアドバイザーが、当社独自基準の審査を経て参画します。2026年内サービス開始予定（有料職業紹介事業 許可申請準備中）。

## 4. 3週目: API自動投稿への移行

1. [developer.x.com](https://developer.x.com) に**このアカウントで**サインアップ（従量課金。$10無料クレジット）
2. `tools/x/README.md` の手順でキー4点を発行 → Claude Code 環境設定の環境変数に登録
3. ネットワークポリシーで `api.x.com` を許可
4. ドライラン → テスト投稿1件 → 日次自動投稿ルーティン開始（週5本ペースを維持。頻度を急に上げない）

## 5. note アカウント開設（**凍結中・任意** → [v2戦略](./sns-strategy-v2.md)で2媒体特化に変更）

v2戦略によりnoteは当面使用しない。将来SEO資産として再開する場合の手順として残す:

1. [note.com](https://note.com) にメールアドレスで登録（Gmailエイリアス可。後から変更可）
2. **note ID（URLになる英数字）**: `markgate_【氏名ローマ字】` または氏名ベース。後から変更可能だがURLが変わるので早めに確定
3. **クリエイター名**: 「【氏名】｜MarkGate代表」
4. **プロフィール文**（140文字制限・138文字。コピペ用）:

> MarkGate株式会社 代表。実績トップクラスのキャリアアドバイザーを審査制で束ね、求職者が"指名"できるハイクラス転職プラットフォームを準備中。創業の思想と業界の構造、アドバイザーの選び方を「教科書」として書き溜めます。個別の求人紹介・相談は行っていません（許可取得前）。

5. ヘッダー画像はXと共通のブランドテンプレ（ネイビー×ゴールド）を後日設定
6. マガジン「ハイクラス転職の教科書」の作成は目次公開時（初月内）でよい
7. 最初の公開記事＝創業マニフェスト（`docs/note-manifesto.md`）。公開後、そのURLをXの固定ポストに設定

## 6. やってはいけないこと（凍結・ブランド毀損の防止）

- 開設直後のAPI連携・予約投稿ツール接続
- 1日10件を超えるフォロー、フォロー/アンフォローの繰り返し
- 同一文面の連投、短時間の連続投稿
- プレゼント企画・相互フォロー企画への参加（ブランド毀損＋スパムシグナル）
- 個別の転職相談への回答（許可取得前。DM定型文は戦略書 §8-2 参照）
