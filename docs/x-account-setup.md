# X 新規アカウント開設・立ち上げ手順（代表個人）

**準拠**: [SNS戦略書](./sns-strategy.md) §5 アカウント設計 ／ **作成日**: 2026年7月5日

新規アカウントは開設直後の数週間が最も凍結されやすいため、「手動ウォームアップ2週間 → 3週目からAPI自動投稿」の段階移行で立ち上げる。

---

## 1. 開設日にやること（30分）

- [ ] X アカウント開設（代表実名）。ハンドルは「氏名ローマ字」または「氏名＋markgate」形式
  - 例: `@taro_markgate` / `@yamada_markgate`（本名が決まり次第確定）
- [ ] **電話番号認証を必ず完了**（凍結耐性の基本）
- [ ] 2要素認証を有効化
- [ ] プロフィール設定（下記§2の文をコピペ。ヘッダー画像はネイビー×ゴールドのブランドテンプレで後日差し替え可）
- [ ] **X Premium に加入**（月額約1,000円〜。凍結耐性・リーチ・リプライ表示順・信頼シグナル。実質必須）
- [ ] 同日にハンドルの一括確保: X公式（`@MarkGate_jp` 等）/ note / LinkedIn / Threads
  - 公式アカウントは確保のみ。運用開始はプロフィール整備後
- [ ] **この日はフォロー・投稿をしない**（開設即大量アクションはスパム判定要因）

## 4. 3週目: API自動投稿への移行

1. [developer.x.com](https://developer.x.com) に**このアカウントで**サインアップ（従量課金。$10無料クレジット）
2. `tools/x/README.md` の手順でキー4点を発行 → Claude Code 環境設定の環境変数に登録
3. ネットワークポリシーで `api.x.com` を許可
4. ドライラン → テスト投稿1件 → 日次自動投稿ルーティン開始（週5本ペースを維持。頻度を急に上げない）

## 5. やってはいけないこと（凍結・ブランド毀損の防止）

- 開設直後のAPI連携・予約投稿ツール接続
- 1日10件を超えるフォロー、フォロー/アンフォローの繰り返し
- 同一文面の連投、短時間の連続投稿
- プレゼント企画・相互フォロー企画への参加（ブランド毀損＋スパムシグナル）
- 個別の転職相談への回答（許可取得前。DM定型文は戦略書 §8-2 参照）
