## ニュース・メディア系巡回先（毎日の「人に依存しない弾」）

人材・労働市場ニュースへの反応は「構造の解説者」ポジションと相性が最良。個人アカウントと違い毎日ネタが供給され、人間関係リスクもない。

**使い分け**: 大手メディアのポストへの**リプライ**（そのポストの読者に露出）と、ニュースへの**引用ポスト**（自分の投稿としてストック化・こちらを優先）の2型。引用ポストは平日1本の在庫投稿とは別枠で、ニュースがある日だけ追加する。

| 巡回先 | 見るもの | 反応の角度 |
|---|---|---|
| @nikkei（日本経済新聞） | 転職市場・雇用・賃金・人材各社の動向記事 | 記事が報じた事実の「業界構造上の意味」を1段深く解説 |
| @NewsPicks | キャリア・組織・労働市場特集 | 特集テーマに実務の一次情報を補足 |
| @Toyokeizai / @diamond_online | 転職・年収・管理職特集 | 同上。特集は保存型リプライが伸びやすい |
| @itm_business（ITmedia） | HRテック・人材業界動向 | テック文脈に「それでも残る人の価値」の視点 |
| 厚生労働省の統計発表（転職者数・有効求人倍率・雇用動向調査） | 発表日をカレンダー管理 | 統計の読み方解説は引用ポストの鉄板ネタ。図解1枚と好相性 |
| リクルートワークス研究所・doda・マイナビの市場レポート | 転職市場レポート・年収調査の公表 | ハイクラスレンジに絞った読み解きで差別化 |
| PR TIMES（人材カテゴリ） | 競合・人材各社のリリース | **競合のニュースは論評しない**（名指し批判禁止の原則）。業界全体の動きとして扱える場合のみ |

**ニュース反応の注意**:
- 競合サービスの値上げ・不祥事・リストラ等のニュースには触れない（批判に見えた時点でブランド毀損）
- 速報への脊髄反射をしない。一次資料（統計原文・リリース原文）を確認してから書く
- 労働政策・解雇規制など政治性を帯びるテーマは「データの解説」までに留め、賛否を表明しない

## 運用ルール

1. **同一アカウントへのリプライは週1件まで**（張り付きは不気味。30件に分散させる）
2. 1件10〜15分。相手の投稿の文脈を読み、**本文より価値のある補足**（データ・構造・実務の一次情報）だけを書く。「勉強になります」型は書かない方がまし
3. 反論・訂正はしない。相手の論を立てた上で「補助線を1本足す」のが基本姿勢
4. 政治・炎上中の話題・特定企業批判のスレッドには、相手が第一群でも**絡まない**
5. 自社への言及はリプライではしない（プロフィールに任せる）。聞かれたら答える
6. 毎週金曜、リプライ→プロフィールアクセスの反応を記録し、反応の良い相手に翌週の配分を寄せる
7. 森本氏・高野氏・末永氏・松本氏ら**同業プロは、リプライ関係の構築がそのままアドバイザー第1期生打診（45〜60日目）の下地になる**。特に丁寧に
