# "担当者ガチャ"を、終わらせる。——MarkGate創業マニフェスト

## キャリアの質は、"誰と出会うか"で決まる

同じくらいの経験と能力を持つ二人が、ほぼ同時期に転職活動を始めたとします。

一人は、業界を深く知り、本人がまだ言葉にできていない希望まで汲み取るキャリアアドバイザーに出会いました。市場価値を丁寧に見極め、表に出ない上位のポジションを引き出し、時には「今は動くべきではない」とまで言ってくれる伴走者です。

もう一人は、手持ちの求人を機械的に流すだけの担当者に当たりました。面談は職務経歴書の確認で終わり、届く求人は希望とすれ違い続け、返信を急かすメールだけが定期的に来る。

数年後、二人のキャリアには説明のつかない差がついています。差を生んだのは能力ではありません。**「誰に相談したか」**でした。そして二人とも、自分の担当者が良かったのか悪かったのか、比較する術がないまま今日に至ります。

私がMarkGateを創業したのは、この構造を放置できなかったからです。

## "担当者ガチャ"は、誰の悪意もなく起きる

転職エージェントの担当者は選べず、当たり外れは運次第——いわゆる「担当者ガチャ」という言葉は、すっかり定着しました。

最初に申し上げたいのは、これは**誰かの怠慢や悪意の結果ではない**ということです。分解すると、原因はすべて業界の構造に行き着きます。

1. **担当者は、求職者との相性ではなく社内都合で割り当てられる。** 稼働状況、担当業界の割り振り、育成計画。組織運営としては当然の論理ですが、「この求職者に最も適した担当者は誰か」という観点が最優先される保証はありません。
2. **力量の事前情報が存在しない。** 経験1年目でも20年のベテランでも、肩書は同じ「キャリアアドバイザー」。経歴・得意領域・支援実績は、担当が決まる前に開示されないのが一般的です。
3. **報酬の設計が「決定」を向いている。** 人材紹介の報酬は入社が決まった時点で発生します。一方、求職者にとっての成功は「数年経っても正解だったと思えること」。この時間軸のズレは、担当者個人の誠実さとは無関係に存在します。
4. **良いアドバイザーほど、新規の求職者に回ってこない。** 優れた人は紹介とリピートで案件が埋まり、その実績は社外からは見えません。

誰にも悪意がないのに、全員が少しずつ損をする。これが私の見てきた、この業界の最も残念な構造です。

## それでも、良いアドバイザーは実在する

誤解してほしくないことがあります。私は人材紹介という仕事を、批判する側に立つつもりはありません。

目先の成約を手放してでも「この転職は、あなたの5年後のためにならない」と言い切る人。求人票に書かれていない組織の実情まで調べ、候補者に不利な事実を先に伝える人。自分の専門外の相談には「私より適した者がいます」と正直に言える人。——そういうアドバイザーが、この業界には確かにいます。私は何人も知っています。

問題は、そういう人たちの仕事が、**構造的に見えない**ことです。誠実さは成約数に表れません。「転職を止めた」という最も尊い判断は、どの実績表にも載りません。良い仕事が良い仕事として選ばれる回路が、この市場にはずっと欠けていました。

だから、作ることにしました。

## MarkGateがやること——審査制と、指名制

MarkGateは、ハイクラス層のための転職プラットフォームです。仕組みは二つだけです。

**一つ。登録できるのは、審査を通過したアドバイザーだけ。**
各人材紹介エージェントで実績を積んだトップクラスのアドバイザーに、当社独自基準の審査制で登録いただきます。審査で確認するのは、成約数の多さではありません。「求職者に不利な事実を伝えた経験を、具体的に語れるか」「『転職しない方がいい』と言った経験があるか」。誠実さを、性格ではなく**行動の履歴**として確認します。

**二つ。求職者が、アドバイザーを"指名"できる。**
登録アドバイザーは、専門領域・経歴・支援のスタンスをプロフィールとして開示します。求職者はそれを読み比べ、自分の意思で相談相手を選ぶ。担当が決まってから信頼を試すのではなく、**信頼できると判断してから担当を決める**。順序を逆にします。

"Mark（一流の証）"を持つ者だけが立つ、キャリアの"Gate（門）"。社名には、それ以上の意味も、それ以下の意味もありません。

## 正直な現在地——まだ、何もありません

ここからは、包み隠さず書きます。

MarkGateには現在、語れる実績が一件もありません。成約数も、利用者の声も、公開できる登録アドバイザーもまだいません。会社は設立準備中で、有料職業紹介事業の許可も申請準備中です。

したがって、許可を取得するまでの間、**求人のご紹介・個別の転職相談・求職者とアドバイザーの引き合わせは一切行いません**。行えないのではなく、行いません。職業紹介の許可制度は、求職者を守るために存在します。誠実さを掲げる会社が、その入口の制度を軽く扱うことはあり得ないと考えています。

実績のない会社が信頼していただく方法は、一つしか思いつきませんでした。**判断の基準と考え方を、すべて先に公開すること**です。

## 三つの約束

1. **審査基準の全文を公開します。** 何を確認し、なぜその項目を置いたのか、理由まで含めて開示します。公開した基準は、私たち自身を縛ります。それでいいと考えています。
2. **連載「ハイクラス転職の教科書」を書き続けます。** エージェント業界の構造、アドバイザーの選び方、ハイクラス転職の実務。転職を考えていない方にも、ご自身の市場と冷静に向き合う道具として使っていただける体系を、週1本ずつ積み上げます。
3. **創業の途中経過を、毎月報告します。** 許可申請の進捗、制度設計で悩んでいる論点、遅れているならその理由。月1回のニュースレター「MarkGate 創業記録」で、売り込みなしの現在地をお届けします。

実績は、後からしか作れません。しかし基準は、最初から示せます。答え合わせの材料を先にお渡ししておきますので、私たちがぶれたときは、この文書を根拠に指摘してください。

キャリアの重要な意思決定が、偶然割り当てられた誰かの力量に左右される——その状態を、当たり前だと思わなくていい市場を作ります。

医師を選ぶように、弁護士を選ぶように、キャリアの伴走者を自分の目で選ぶ。それが特別なことではなく、当たり前になる日まで、この文書を原点として進みます。
