# MarkGate株式会社 コーポレートサイト

ハイクラス層の求職者向けに、各人材紹介エージェントの「トップキャリアアドバイザー」だけが
登録できる転職プラットフォーム事業「MarkGate（マークゲート）」のコーポレートサイトです。

## コンセプト

> **トップアドバイザーだけが、開ける扉。**

- **トップアドバイザー限定（審査制）** — 各エージェントの実績上位アドバイザーのみが登録
- **ハイクラス・エグゼクティブ特化** — 経営幹部・管理職・高度専門職
- **アドバイザーを“選べる”** — 求職者が実績・専門領域を見て指名できる

## 求職者向けプラットフォーム（`/platform`）

コーポレートサイトが掲げる「アドバイザーを“選べる・指名できる”」体験を、実際に動く求職者向けアプリとして実装したものです。ビルド不要の静的サイト＋クライアントサイドJSで動作し、データはお使いのブラウザ（`localStorage`）に保存されます。

### 主な機能

| 要件 | 実装 |
| --- | --- |
| 各CAのプロフィール閲覧 | `advisor.html?id=` … 経歴・専門領域・強み・実績・レビューを表示 |
| フィルタ・検索 | `advisors.html` … 業界／職種／対応年収／地域／支援スタンスでの絞り込み、キーワード検索、並び替え、URL同期 |
| CAの指名 | プロフィール・一覧の「指名する」から指名モーダル（メッセージ添付可） |
| 指名するとCAに連絡がいく | 指名を記録し、成功画面 → `inbox.html`（アドバイザー受信箱デモ）で“届いた指名”を可視化。`mailto:` での直接連絡にも対応 |
| マイページ | `mypage.html` … 職務経歴書・学歴・スキル/資格・希望条件を記載・編集・保存。入力状況バー、指名履歴の確認・取消 |

### 使い方

1. コーポレートトップの「アドバイザーを探す」から `/platform/advisors` へ
2. 条件で絞り込み、気になるアドバイザーの「指名する」を押す
3. 初回は `/platform/mypage` で基本情報（氏名・メール）を入力（アドバイザーへの連絡に使用）
4. 指名すると受信箱デモ（`/platform/inbox`）とマイページの指名履歴に反映

### 検証

Playwright による E2E 検証（`scratchpad/verify.mjs` 相当）で、全ページのロード・検索/絞り込み・指名フロー（指名→受信箱→履歴→指名済み表示）・プロフィール保存の永続化を確認済みです。

### 本番化に向けた差し込み（現状はフロント完結のデモ）

- 会員認証・サーバDBへの置き換え（現状は `localStorage`）
- 指名時のアドバイザーへの実メール／通知送信（現状は記録＋`mailto:`）
- アドバイザーデータの実データ化（現状は `platform/assets/js/data.js` のシード）
- 指名ステータスの遷移（返信・受諾など）とアドバイザー側管理画面

## 営業資料（`/sales`）

人材紹介エージェント向けの提案資料（スライド15枚・A4横）です。ブラウザで `/sales` を開き、
`Ctrl / ⌘ + P` →「PDFに保存」（A4横・余白なし・背景のグラフィックON）でそのままPDFになります。

- 構成：表紙 → サマリー → 業界課題 → 発想の転換（スカウト型→指名型） → サービス概要 → 仕組み →
  エージェントのメリット → チャネル比較 → 審査 → 掲載イメージ → 料金（想定） → 導入の流れ →
  FAQ → FAQ（情報の取り扱い・ご契約） → 会社概要/CTA
- 実績値・料金・所要期間は未確定のため、資料内では「予定」「想定」「目安」と明示しています。確定後に差し替えてください。
- サイトURL・問い合わせ先・リリース時期の確定後は、P.15のCTA周りとP.12の先行登録案内を差し替えてください。

## ローカルでの確認

ビルド不要の静的サイトです。任意のHTTPサーバで開けます。

```bash
# 例：Python
python3 -m http.server 8000
# → http://localhost:8000

# 例：Node
npx serve .
```

## デプロイ

`vercel.json` を同梱しているため、Vercel にそのまま静的サイトとしてデプロイできます。
（GitHub Pages / Netlify / S3 など任意の静的ホスティングでも動作します）
